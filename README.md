# **Trainspotting (1996)**
Trainspotting is a british dark comedy-drama film directed by Danny Boyle inspired by the 1993 novel of the same name. 
The film takes place throughout Edinburgh and London while exploring the dark themes about the troubles of escaping addiction and letting go of the people repeating the same cycle.
---
## *Notable Actors*
1. Ewan McGregor as Mark Renton
2. Jonny Lee Miller as Simon Williamson
3. Robert Carlyle as Francis Begbie
4. Ewen Bremmer as Daniel Murphy
